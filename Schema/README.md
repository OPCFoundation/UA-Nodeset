### `Opc.Ua.NodeSet2.Services.xml`, `Opc.Ua.NodeSet2.xml`

These are the same NodeSet: `Opc.Ua.NodeSet2.Services.xml` is `Opc.Ua.NodeSet2.xml` with a filter applied. They declare the one model, so both are listed against every specification above.
